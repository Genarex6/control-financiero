# Finora · Control financiero

Abre `index.html` en un navegador moderno. Los datos se guardan localmente en el navegador.

## Incluye

- Dashboard inteligente con presupuesto, disponible, gasto y deuda pendiente.
- Registro de gastos con categorías y gráfico comparativo.
- Tarjetas de deuda con progreso, vencimiento, edición, eliminación y abonos.
- Calendario de próximos vencimientos e historial consolidado de pagos.
- Exportación de gastos, deudas y pagos en CSV compatible con Excel.

Los datos de esta nueva versión usan claves `finora_*` en LocalStorage, para que no interfieran con los de la versión anterior.
